# Portfolio — frontend

Личное портфолио: проекты, навыки, опыт, блог и список репозиториев с GitHub. Контент подгружается из [portfolio-backend](https://github.com/bogdan-kabanov/portfolio-backend) и редактируется через [portfolio-admin-panel](https://github.com/bogdan-kabanov/portfolio-admin-panel).

**Демо:** https://bogdan-kabanov.github.io/portfolio-frontend/

## Возможности
- Секции: проекты (с детальными страницами), навыки, опыт, блог с markdown, GitHub-репозитории
- Переключение языка RU/EN
- Анимированный фон (Matrix canvas), кастомный курсор
- Авторизация через модальное окно

## Стек
React 19, Vite, ESLint

## Запуск
```bash
npm install
npm run dev      # режим разработки
npm run build    # production-сборка
```
